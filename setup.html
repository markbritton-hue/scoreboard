Untick a game to drop it from the ticker. Feature puts that one score on the right side of the same overlay.

Tick the games you want on the ticker.

Remote control (recommended)

With this on, the overlay in OBS / H2R follows this page by itself, within about a minute: ticking games, the date, Feature and Take off screen. You copy the overlay link once and never again. It needs a GitHub access token so this page can save your choices to your repo.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → scoreboard. Permissions → Repository → Contents: Read and write.
  3. Generate it, copy it, and paste it below. It stays in this browser only.
